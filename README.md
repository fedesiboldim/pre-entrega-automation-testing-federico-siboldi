# Pre-Entrega: Automatización con Selenium y Pytest

## Propósito del Proyecto
Automatización de flujos de prueba sobre el sitio SauceDemo (login, catálogo y carrito de compras) utilizando buenas prácticas y esperas explícitas.

## Tecnologías Utilizadas
- Python 3
- Selenium WebDriver
- Pytest
- pytest-html
- Git y GitHub
